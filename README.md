# MoonXPT

SAS XPORT V5 streaming library and native CLI written in MoonBit.

Development in progress; the current milestone is recorded in
[docs/progress.md](docs/progress.md). The full authorized scope is in
[docs/task-spec.md](docs/task-spec.md).

Toolchain: moon 0.1.20261012 / moonc 0.10.15+943464bfa; C compiler for native I/O.

```sh
moon check --target native
moon test --target native
moon build --target native
moon run cmd/moonxpt --target native
```
